# 语音与音响改造记录（小智）

[English version](voice_speaker_retrofit.md)

2026-10-26 ~ 11-08。给 Open Duck 装上"小豆"：喊一声"你好小豆"，就能用语音让鸭子停下、走路、转弯、点头、蹲下、查电量。

## 现状（2026-11-08）

| 项目 | 状态 |
| --- | --- |
| 唤醒词 | 「你好小豆」（自改固件） |
| 能用的语音指令 | 停下、往前走（最多 5 秒）、转弯（最多 90°）、点头 / 摇头 / 歪头 / 抬头、查状态（电量、前方距离）、蹲下、站起来、关机（两步确认） |
| 故意不开放 | 上力、开始运行、卸力：只能在手机上按，防止鸭子没放好就被叫起来 |
| 安装位置 | 喇叭和语音板都装在胸前盖板上，线不穿脖子 |
| 供电 | 电源板开关后面取电，经 5 V 降压模块接到语音板排针 |

## 硬件

- **语音板：** 微雪 ESP32-S3-AUDIO-Board（Φ58 圆板，两个麦克风 MIC1/MIC2，ES8311/ES7210 音频芯片，背面 SPK 喇叭插座、BAT 电池插座，2×9 排针）。买的是带喇叭盒的套装，只用电路板和喇叭。
- **喇叭：** 套装自带的单体，约 Ø40，43 g。
- **降压模块：** 红色 USB 车充板（6~24 V 输入，固定 5 V，USB-A 输出），实测 5.03 V。
- **5 V 线：** 一根只有红、黑两根线的 USB-A 充电线，剪开后红线 → 5V、黑线 → GND。

## 接线

1. **取电位置：** 电源板"输出 2"那两个 WAGO 上（和给树莓派供电的 UBEC 并联），在电源开关后面。关开关，语音板也一起断电，不会偷偷耗电。
2. **降压模块输入：** 背面离 USB 口最远的 + / − 焊盘。千万别接反。
3. **输出：** USB 口 → 充电线 → 杜邦母头 → 语音板排针**上排**、靠 MIC1 的那一头：最外侧是 **5V**，紧挨着的是 **GND**（喇叭插座在另一头）。
4. **先量再接：** 先单独量降压模块输出（应为 5.0~5.3 V），对了再插语音板。
5. **注意：** 鸭子开着时不要再插语音板的 USB-C，两路 5 V 会冲突；刷固件先关鸭子开关再插 USB。
6. 插拔任何线都先关电。

## 安装（胸前盖板）

- **喇叭壳：** 先打一个 5 mm 高的"喉口试片"：唇口 Ø34，锥孔 Ø39 → Ø43（8 mm 内），外径 Ø49 = 盖板上的喇叭孔。喇叭从后面推进去，卡在锥孔里刚好。试片合适后，正式壳子的前端就照这个尺寸做。
- **语音板支架：** 和喇叭壳做成一体，3 个打印卡扣卡板子，再加一颗 M3 螺丝做第三个固定点（热压螺母）。麦克风朝盖板外面，盖板上自己钻麦克风孔。
- **踩过的坑（第一版）：**
  1. 喇叭壳前端做成了平的，没做出锥形，喇叭推不进去；
  2. 盖板上的螺丝柱实际 12 mm（不是 10 mm），壳子和盖板之间差了 2 mm；
  3. 卡扣只扣住 0.1 mm，等于没扣上。
  第二版都改了，但用户选择不重打：把黄色螺丝柱锯短 2 mm，卡扣改成螺丝固定。
- **教训：** 照片估的尺寸会差 2 mm 左右，关键接口先打薄试片验证（0.6 mm、3 层，标签刻 0.2 mm 深）。

## 重量与重心

| 部分 | 重量 |
| --- | --- |
| 前盖板本身 | 43 g |
| 喇叭 + 语音板 + 支架 | 58 g |
| 合计 | 101 g |

58 g 加在最前面，整机重心往前约 1.9 mm。同期换的新头盖轻了 53 g，往后约 1.4 mm；合计往前约 0.5 mm，对走路有利（仿真里摔倒都出在重心更靠后的时候）。后来按真实重量重新训练了一版（od27）。

## 固件

- 先刷微雪官方 v2.4.0（esptool，0x0 地址整包），连 Wi-Fi、在 xiaozhi.me 激活（账号、Wi-Fi 密码、激活码都由用户自己操作）。
- 自改固件 9.4.0（补丁在 `xiaozhi/`）：
  - 唤醒词只留「你好小豆」（multinet 自定义词，不走降噪，只读一路麦克风）；
  - 本地「停下」：不经云端，直接通过局域网 HTTP 让鸭子停；
  - 倒计时工具：到点由云端说一句话（提醒文字要短，长了云端会拒收）；
  - 麦克风增益工具。
- 测试语音时要关掉电脑上占着的串口（COM 口），开着会影响它工作。

## 和鸭子连起来（MCP 桥）

- 树莓派上跑 `robot_mjlab/xiaozhi_bridge.py`（systemd 服务 `xiaozhi-bridge`，开机自启）：主动连到小智控制台的 MCP 接入点，把语音工具调用转成鸭子服务的 `/cmd` 指令。家里不用开放任何端口。
- **接入点地址等于钥匙**：只放在树莓派的私有文件里，绝不进聊天、截图或仓库。
- 工具设计：
  - 每个工具只做一件安全的事，走路、转弯都有上限；
  - 需要确认的动作（关机）拆成两个工具：第一个只提问，3~30 秒内再调第二个才执行。用布尔参数做确认不行，大模型不会填；
  - 状态工具顺带报超声波前方距离。

## 经验

1. **语音"停"不能当急停**：从说话到动作有时要十几秒。真正的急停用本地「停下」或手机。
2. **小豆在一段对话开始时记下能用的工具清单，这段对话里不再更新。** 鸭子刚开机、树莓派还没连上时就唤醒它，这段对话里就看不到鸭子的工具。所以开机后等约 1 分钟，说「拜拜」结束旧对话，再重新唤醒。
3. 小智后台的对话记录能看到每次调用了哪个工具，排查问题很方便。
4. 先在桌面上把整条链路（唤醒 → 云端 → 树莓派 → 舵机）跑通，再装进鸭子。
5. 装进胸腔后要再测一次唤醒距离：外壳会挡声音。
