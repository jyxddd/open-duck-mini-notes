# 蹲下 / 站起记录

[English version](squat_stand_notes.md)

Open Duck Mini v2 用 mjlab（Microduck 方法）训练蹲下、站起，从 2026-10-31 到 11-03 的完整过程。

## 现状（2026-11-03）

| 项目 | 结果 |
| --- | --- |
| 当前模型 | `mj_sit8_7000`（腿部 kp 20），备用 `mj_sit6_6750` |
| 木地板，不用手扶 | sit6 6/6 次成功，sit8 6/6 次成功 |
| 蹲下幅度 | 髋 41°、膝 21°、踝 16°（相对站立姿势），身体降低约 3.4 cm |
| 蹲下速度 | 1.4 秒到 80% |
| 站起速度 | 0.3 秒到 80%，**太快**，sit9 正在把它放慢 |
| 橡胶防滑垫 | **不行**：sit6 只能蹲一次，sit8 第一次就侧倒 |
| 扭屁股 | 两个模型都有：蹲着时左右、转动方向晃 6～8°/s |

## 任务怎么搭的

- 把 Microduck 的 SitStand 任务移植成 `Mjlab-SitStand-Flat-OpenDuck`（`mjlab_port/tasks/openduck_sitstand_env_cfg.py`）。它通过替换 Microduck 模块里的常量来换成 Open Duck 的机器人和姿势。
- 蹲 / 站由指令第 1 个数决定（1 = 蹲下，0 = 站起），走路速度那 3 个数在蹲起模型里没用。
- **观测顺序和走路模型不同**：重力方向紧跟在陀螺仪后面（走路模型里重力在指令后面）。我们弄错过一次，模型 1 秒就翻。树莓派这边 `robot_mjlab/mjlab_walk.py` 按文件名里有没有 `sit` 来选顺序。
- 蹲起模型的关节目标限位比走路宽：髋前后到 ±1.35，膝到 1.7 rad（见下面的膝盖极限）。

## 版本历程

每次只改一个参数，在上一个好版本的基础上接着训练。

| 版本 | 改了什么 | 模拟 | 真机 |
| --- | --- | --- | --- |
| sit1 | 跪坐（小腿着地） | 3000 轮学不会站起来，硬起身要 1.9 N·m，还会往后翻 | 未测 |
| sit2 | 改成脚掌贴地的深蹲 | 1000 轮就能蹲下站起，但只降 2.8 cm | 在支架上抖 8～10°/步（悬空正常）；地面上蹲得很浅、抖 |
| sit3 | 动作变化惩罚 ×4 | 第 5000 轮在 kp 20、25 都行 | 第一次蹲成功（膝 21/20°），之后卡在站姿 |
| sit4 | 膝盖蹲到 2.1 rad | — | **停**：手掰实测膝盖极限只有 +1.75 rad |
| sit5 | 膝 1.75 | — | 停，贴着极限没有余量 |
| sit6 | 膝 1.65、髋 1.3、踝 0.4，模拟膝盖限位 1.76 | 第 6750 轮 11 种条件 0 摔 | **木地板 6/6**；起身 0.5～1 秒，太快 |
| sit7 | 身体上下速度超过 5 cm/s 就罚 | 起身变慢了，但 kp 25 下开头 0.5 秒内摔 8/10 | 不用 |
| sit8 | 脚底摩擦随机范围 0.7–1.3 改成 0.3–2.0 | 摩擦 2.0 时 4/4 能蹲（sit6 0/4），中途摔 0 次（sit6 3 次） | **木地板 6/6**；防滑垫第一蹲就侧倒 |
| sit9 | 起身斜坡 2 秒改成 4 秒 | 训练中 | — |

## 关键发现

1. **膝盖真实极限 +1.75 rad。** 用手把腿掰到底读编码器得到。模型里原来写的 2.4 是错的，按它设计姿势会让真机膝盖顶死。现在模拟里的膝盖限位设成 1.76，目标裁剪到 1.7。
2. **地面摩擦会让蹲起失败。** PLA 鞋底在上漆木地板上摩擦约 0.3，橡胶垫远高于 1.3，都在原训练范围（0.7–1.3）之外。模拟里把摩擦设成 2.5，能复现"蹲不下去、身体后仰 7～10°、kp 25 时摔倒"。sit8 扩大了范围，模拟里解决了。
3. **但防滑垫上的问题不只是摩擦。** sit8 在垫子上第一次蹲就侧倒：两边髋关节收到的指令是对称的（20 多度），左髋跟上了，右髋在负重下只跟了一半，身体歪到 41°。垫子软、脚会陷，模拟里没有这个。
4. **右腿没坏。** 在支架上做空载测试（`tools/stand_sine_test.py`），10 个腿部舵机左右一致：摆动跟随率 0.95～1.01，滞后 60～80 ms，阶跃 0.10～0.12 秒到位。走路时膝盖只跟到一半，是负重和速度造成的，两条腿一样。
5. **起身太快不好治。** 在指令上做斜坡没用，模型在 0.35 左右就直接切换。sit7 罚速度又导致起步摔。sit9 改的是训练里的姿势斜坡时长。
6. **蹲起模型必须用 kp 20。** sit6 在 kp 30 下模拟里蹲不下去，而走路模型在 kp 30 下抬脚更高。服务器给每个模型单独设 kp（`MODEL_KP`）。
7. **起步会猛晃一下。** sit8 刚开始 0.4 秒左右晃 11～15°。模拟里偶尔"开头 1 秒就倒"，真机上也有这个现象的轻微版本。
8. **扭屁股不是 sit8 新带来的。** 和 sit6 的日志对比：陀螺仪左右约 3°/s、转动 6～8°/s，髋侧摆 11～15°，两个模型几乎一样。

## 怎么用

- 手机页面选"蹲下站起 sit8"，按"蹲下 / 站起"。选了蹲起模型就不能走路，要先换回走路模型。
- 一定在硬地板上，防滑垫上会倒。
- 下一步：合成一个"走 + 蹲"模型，按蹲下时服务器先停下站稳 2 秒，再自动换成蹲起模型。模拟里验证过：站稳 2 秒再换 4/4 成功，一停就换 1/4 摔倒。

## 模拟检查

```bash
python tools/mjlab_sim_check.py --onnx mj_sit8_7000.onnx \
  --schedule "3:0,6:1,5:0,8:1,5:0,8:1,3:0" --ground --kp_legs 20 --friction 2.0 \
  --vin 7.8 --knee_range 1.76 --clip --imu_delay 2 --backlash 1 --com_x -12 --gyro_noise 0.1 --seed 1
```

时间表每段是"秒数:蹲下标志"，上面是站 3 秒、蹲 6 秒、站 5 秒……共蹲三次。每段输出身体高度和倾角，站着约 0.16 m，蹲下约 0.128 m。`--friction` 改地面摩擦，`--seed` 换随机种子，每个候选至少跑两个种子。走 ↔ 蹲切换用 `--sit_onnx`，时间表第 9 个数为 1 的段用蹲起模型。

> 2026-11-07 补充：考试时把鸭子放在 0.155 m 高度开局，脚陷进地里约 5 mm，开局 1 秒内就被弹倒。训练里站立开局是 0.162~0.172 m，以后蹲起考试都加 `--start_z 0.167`。
